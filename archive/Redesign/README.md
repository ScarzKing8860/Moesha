# Moesha Redesign Prototype

This folder is the replacement candidate. The original root app remains unchanged.

## Open

Open `index.html` directly in a browser.

## Included

- Workspace, Library, Planner, and Tools views
- Enter-to-send chat behavior with Shift+Enter for line breaks
- Chat replies and topic shortcuts
- Persisted planner items, focus tasks, recent threads, and timer values
- Voice input fallback and optional ElevenLabs settings
- Responsive desktop and mobile layout
- Moesha assistant artwork

## Replacement checklist

1. Test chat, planner commands, timer, voice input, and topic shortcuts.
2. Check the page at desktop and mobile widths.
3. Replace the original root `index.html`, `script.js`, and `style.css` only after approval.
4. Copy the image asset path with the replacement or update the paths to match the final location.
